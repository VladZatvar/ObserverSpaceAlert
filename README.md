# ObserverSpaceAlert

## Опис проєкту

Це консольна Java-програма для демонстрації шаблону проєктування Observer.

Проєкт моделює систему сповіщення екіпажу космічної станції про зміну рівня небезпеки. У роботі реалізовано два підходи:

- програма 1 — без використання патерна Observer;
- програма 2 — з використанням патерна Observer.

## Умова завдання

Потрібно дослідити шаблон проєктування Observer, описати реальну ситуацію, у якій його можна застосувати, реалізувати цю ситуацію двома способами та порівняти підходи.

У проєкті розглядається ситуація, коли система космічної станції змінює рівень небезпеки, а члени екіпажу повинні отримати відповідні повідомлення.

## Реалізація без Observer

У класі `AlertSystemWithoutObserver` система сповіщення напряму викликає окремі методи повідомлення:

- командира;
- інженера;
- медика.

Такий підхід працює, але має недолік: якщо потрібно додати нового отримувача повідомлень, доведеться змінювати сам клас системи сповіщення.

## Реалізація з Observer

У реалізації з патерном Observer створено:

- інтерфейс `Observer`;
- клас `SpaceAlertSystem`, який зберігає список спостерігачів;
- класи-спостерігачі `CommanderObserver`, `EngineerObserver`, `MedicObserver`.

Коли рівень небезпеки змінюється, система автоматично повідомляє всіх підписаних спостерігачів через метод `update()`.

Також реалізовано можливість відписати спостерігача від системи повідомлень.

## Основні класи

- `Main` — запуск і демонстрація обох підходів;
- `AlertSystemWithoutObserver` — реалізація без патерна;
- `Observer` — інтерфейс спостерігача;
- `SpaceAlertSystem` — система сповіщення, за якою спостерігають;
- `CommanderObserver` — спостерігач-командир;
- `EngineerObserver` — спостерігач-інженер;
- `MedicObserver` — спостерігач-медик.
